# Аналіз даних для прогнозування діабету

Магістерський проєкт на Python/Jupyter. Поточний етап — дослідницький аналіз даних та підготовка попередньої обробки ознак.

## Виконано

- Завантажено датасет: 100 000 записів, 9 стовпців (8 ознак та цільова змінна `diabetes`).
- Проведено EDA та побудовано 7 графіків: розподіл класів, вік, BMI, HbA1c за класами, глюкоза за класами, частка діабету за віковими групами, матриця кореляцій.
- Видалено 3 854 дублікати; залишилося 96 146 записів.
- Виконано стратифікований поділ за цільовим класом: навчальна вибірка `(76916, 8)`, тестова — `(19230, 8)`.
- Частка класу 1 в обох вибірках — 8,82%; класу 0 — 91,18%.
- Перевірено, що навчальні та тестові індекси не перетинаються.
- Створено конфігурацію попередньої обробки через `sklearn` `ColumnTransformer` та `Pipeline`: 6 числових і 2 категоріальні ознаки.

## Поточний стан

Моделі ще не навчалися. Для підготовленого конвеєра `fit` ще не викликався. Експорт чотирьох CSV-файлів навчальної та тестової вибірок ще НЕ виконано.

Подальший крок — навчити попередню обробку лише на навчальній вибірці та застосувати її до тестової, після чого перейти до навчання й оцінювання моделей.

## Основні файли

- `01_data_analysis_EDA.ipynb` — дослідницький аналіз.
- `02_preprocessing.ipynb` — поділ даних і налаштування попередньої обробки.
- `03_model_training.ipynb` — заготовка для навчання моделей.
- `04_model_evaluation.ipynb` — заготовка для оцінювання моделей.
- `eda_diabetes_step1.py` — допоміжний скрипт аналізу.

## Локальний запуск

Потрібні Python 3, Jupyter, pandas, numpy, matplotlib, seaborn та scikit-learn. За потреби створіть локальне середовище:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install jupyter pandas numpy matplotlib seaborn scikit-learn
jupyter notebook
```

Версії залежностей поки не зафіксовано. Вихідний файл `diabetes_prediction_dataset.csv` потрібно отримати окремо з дозволеного джерела та розмістити за шляхом, який використовує ноутбук. Перед поширенням даних перевірте умови їх використання.
